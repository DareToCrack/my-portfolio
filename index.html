VulnScout — Automated Vulnerability Scanner

✦ Newest

Problem: A small business has no easy way to see what is exposed on its own network — which ports are open, which services are outdated, and what an attacker would find first — without enterprise tooling or a consultant.
Built: An automated vulnerability scanner that drives Nmap from Python, parses its XML output with a custom pure-Python parser, and turns open ports and scan results into severity-rated findings with plain-language explanations, concrete remediation steps and CVE references. Three scan profiles (Quick, Standard, Deep), an explainable 0–100 posture score you can audit, a “fix first” list ordered Critical to Low, scan history, HTML / CSV / JSON reports, and a CLI. Every scan requires an explicit authorisation confirmation and targets are capped at a /24; a seeded demo network lets you explore the whole UI without scanning anything real.

URL Sentinel — Malicious URL Detector

Web Security

Problem: A single bad link — a typosquatted domain, a look-alike login page, a shortened URL hiding its destination — is all it takes to hand credentials to an attacker, and most people click before they check.
Built: A browser extension that detects malicious URLs in real time. A 15-check heuristic engine scores every address 0–100 and explains each finding in plain language; malicious sites are stopped with a warning page before they load, and suspicious links on pages get a warning marker before you click. All analysis runs offline on your device, with an optional Google Safe Browsing lookup when you add an API key.

Privacy Scanner — Mobile App Privacy Scanner

Mobile Security

Problem: Apps on a phone can ask for far more access than they need — microphone, precise location, contacts, SMS — and most people have no way to see which apps are overreaching.
Built: A mobile app privacy scanner that audits installed apps, flags risky permissions in plain language, scores every app 0–100 for privacy risk, and detects over-privilege — permissions that don't fit the app's category — with every rating mapped to OWASP MASVS controls. A native Android module reads installed apps and their permissions on-device; on web and iOS it runs a demo mode with 17 fictional apps, no install needed.

SecureShare — Encrypted File Transfer

Encrypted File Sharing

Problem: Sharing sensitive files usually means trusting the server with the plaintext — and with the decryption key.
Built: An end-to-end encrypted file transfer app where files are encrypted in the browser before upload. The decryption key lives only in the share link's URL fragment and is never sent to the server, filenames are encrypted separately, and every download is verified for tampering. Shares can expire on a schedule or burn after a single reading.

PhishSim — Phishing Simulation Tool

Live Demo

Problem: Phishing is still the top way attackers get in, yet most teams have no safe, measurable way to test and train people before a real campaign hits.
Built: A safety-first phishing simulation platform for authorised awareness training — create campaigns, send from 6 templates, track opens / clicks / submits / reports per recipient, and turn results into tailored awareness guidance. Dry-run by default, with an authorisation check and domain allowlist for any live send; simulated logins never store credentials.
