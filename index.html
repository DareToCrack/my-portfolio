SecureShare — Encrypted File Transfer

✦ Newest · On GitHub

Problem: Sharing sensitive files usually means trusting the server with the plaintext — and with the decryption key.
Built: An end-to-end encrypted file transfer app where files are encrypted in the browser before upload. The decryption key lives only in the share link's URL fragment and is never sent to the server, filenames are encrypted separately, and every download is verified for tampering. Shares can expire on a schedule or burn after a single reading.

AES-256-GCM encryptionOptional passphrase · PBKDF2-SHA-256, 600k iterations25 MB upload capExpiry + burn-after-reading38 tests passing13/13 live-server E2E checks

PhishSim — Phishing Simulation Tool

Live Demo

Problem: Phishing is still the top way attackers get in, yet most teams have no safe, measurable way to test and train people before a real campaign hits.
Built: A safety-first phishing simulation platform for authorised awareness training — create campaigns, send from 6 templates, track opens / clicks / submits / reports per recipient, and turn results into tailored awareness guidance. Dry-run by default, with an authorisation check and domain allowlist for any live send; simulated logins never store credentials.
